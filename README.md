# BSG IT Portfolio

## Overview

This repository documents sanitized examples of my professional IT experience while working with Berry Solutions Group (BSG), a managed service provider supporting a variety of customer environments.

The purpose of this portfolio is to demonstrate the technical responsibilities, troubleshooting processes, platforms, and support workflows I have worked with in real-world MSP environments.

All customer-specific information has been removed or generalized. No confidential information, credentials, proprietary documentation, internal screenshots, customer names, IP addresses, ticket numbers, or private configurations are included.
